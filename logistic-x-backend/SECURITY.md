# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Report them privately
through GitHub's **Security → Report a vulnerability** tab on this repository.
Include steps to reproduce, the affected version or commit, and the impact you expect.

We aim to acknowledge reports within 3 business days and to share a fix timeline
after triage.

## Supported versions

Only the latest `main` branch receives security fixes.

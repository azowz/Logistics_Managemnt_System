آخر مراجعة للفصل: **2026-11-11**. التطبيقان في `mesaar-backend/` و`mesaar-frontend/`.
نتائج الفصل الحالية في [SEPARATION_REPORT](../SEPARATION_REPORT.md)؛ جدول المراجعة القديمة
أدناه محفوظ بتاريخ 2026-10-18. لا تثبت هذه النتائج جاهزية إنتاجية شاملة.

- **Implemented:** موجود في الكود ومربوط بمسار أو عامل عند الحاجة.
- **Tested:** شُغّلت الاختبارات المرتبطة فعلًا، ضمن البيئة والنتيجة أدناه.
- **Partial:** تنفيذ جزئي أو مزود غير موصول أو بيانات Mock.
- **Planned:** متطلب أو تصميم لم يكتمل تنفيذه.
- **Deprecated:** مرجع متجاوز محفوظ للتاريخ، وليس العقد الحالي.

## المخاطر الأمنية المفتوحة

1. بعض نقاط client/driver تقرأ بيانات المستأجر كاملة، وبعض الإجراءات الميدانية لا تحصر
   المورد بالسائق المسند؛ يلزم نموذج ملكية وصلاحيات أوضح داخل المستأجر.
2. طبقة الجلسة تستخدم مستأجر المنصة عند غياب السياق. ضُيق JWT القديم بلا tid إلى مستأجر
   المستخدم داخل المعاملة نفسها؛ يظل المسار الجديد الذي ينسى الربط بحاجة لمراجعة.
3. دخول البريد بلا tenant_slug يبحث بين المستأجرين؛ الهاتف غير فريد عالميًا و OTP غير منفذ.
   لا يوجد محدد عام لمحاولات الدخول.
4. حدث التتبع لا ينفذ كل بوابات الامتثال، ويقبل الفاعل من العميل بعد تحقق UUID.
   القبول الذاتي القديم يسند بلا مركبة ويتجاوز بعض بوابات المسار العادي.
5. Webhooks تبقي HTTP داخل المعاملة، ولا تحجز الصفوف ضد كل تداخل؛ DNS Rebinding يحتاج
   ضابط شبكة. التوقيع الصادر بلا Timestamp؛ الوارد غير الصحيح يسجل rejected مع 201.
6. SECRET_KEY مشترك لتوقيع JWT واشتقاق تشفير Webhooks؛ لا تحقق iss/aud حاليًا، وتوكن
   السائق بلا jti. فحص Denylist يتجاوز عطل Redis بتحذير.

## الديون التقنية

- حجز Outbox و Webhook ضد التداخل، وإعادة المحاولة خارج المعاملة؛ شغّل Beat واحدًا.
- حدث بوابة الامتثال يلتزم قبل انتقال الشحنة؛ يلزم توحيد الذرية مع حفظ تدقيق المنع.
- مستودعات Fleet و Users القديمة تلتزم وتحذف فعليًا، بخلاف النمط الأحدث.
- بعض Helpers و Pagination مكررة؛ لم تضاف طبقة تجريد لمجرد تقليل التكرار الشكلي.
- تصنيف IntegrityError في Event Store، و N+1 وبعض الفهارس، تحتاج تحسينًا بعد قياس أثرها.
- فروق ADR: التجزئة و UUIDv7 للإسقاطات وبرج التحكم ومقارنة العقود؛ راجع [القرارات](adr/README.md).
- بناء Native والتشغيل على الجهاز ومراجعة الوصول الشاملة عمل متبقٍ؛ الربط الحي للويب
  والبناء المستقل واختبارات المتصفح موثقة في تقرير الفصل.

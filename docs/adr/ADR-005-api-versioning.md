# ADR-005 — إصدار API والعقد

- **الحالة:** Accepted (الاختيار الافتراضي).
- **التاريخ:** 2026-06-20.

## السياق والقرار

كانت المسارات بلا إصدار وقت القرار. يستهدف التصميم تطبيق السائق ولوحات الويب، فتحتاج
التغييرات غير المتوافقة إلى ضبط. اعتمد بادئة URI **/v1** على APIRouter رئيسي، و OpenAPI
المولد من FastAPI عقدًا، واختبارات توافق في CI. تتضمن الخطة مسودة يدوية
`api/openapi.yaml` تقارن بالمخطط المولد.

## الآثار والقواعد

يسمح /v2 بالتعايش مع/v1، ويمكن توليد SDK من OpenAPI. تغير Base URL للعميل مرة عند إضافة
البادئة. الإضافات المتوافقة تبقى v1؛ حذف/إعادة تسمية الحقول وتغيير الأنواع يحتاج v2.
يعلن Endpoint الوسم والملخص ونماذج الاستجابة والأخطاء.

## المطابقة الحالية

/v1 و/openapi.json منفذان، وتوجد اختبارات لبعض العقود. المسودة اليدوية متقادمة ولا توجد
مقارنة آلية شاملة لها أو بوابة توافق كاملة في CI. لا تعتمد المسودة لتطوير عميل؛ إلغاء
هذا الجزء منالقرار رسميًا يحتاج ADR لاحقًا. راجع [API](../api.md).

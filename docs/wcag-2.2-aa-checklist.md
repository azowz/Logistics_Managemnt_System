# قائمة فحص الوصول — WCAG 2.2 AA

**الحالة: Planned/يحتاج تحققًا.** هذه قائمة عمل للواجهات المستهدفة، وليست شهادة مطابقة
أو حصرًا كاملًا لكل معايير A/AA. Web غير منفذ، و CI لا يشغل Axe أو قارئ شاشة. تطبيق السائق
يحتاج أدوات Native و TalkBack/VoiceOver.

| --- | --- | --- |

|1.4.3|AA| قياس تباين النص في كل حالة؛ 4.5:1 للنص العادي |
|1.4.10|AA| Reflow عند 320px دون فقد أفعال أوتمرير ثنائي غير لازم |

|1.4.12|AA| استيعاب تغير مسافات النص دون قص |
|1.4.13|AA| محتوى Hover/Focus قابل للإغلاق والوصول ويبقى أثناء الحاجة |

Tokens وحدها لا تثبت نسب التباين. احترم تقليل الحركة واختبر النبض والعداد والانتقالات.
اعكس ترتيب الواجهة والأيقونات الاتجاهية دون الخرائط والشعارات، واعزل الهاتف والمعرّفات LTR.
اختبر القص والتكبير ونطق العربية والأرقام وحالات التحميل والفراغ والخطأ ومنع الصلاحية.

عند التنفيذ سجل الشاشة والمنصة والمعيار والنتيجة والأداة والخطوات والتاريخ. يمكن إضافة
Axe للويب عند وجوده، لكنه لا يغطي كل المعايير ولا يعوض الاختبارات اليدوية. تبقى البنود
غير مفحوصة حتى تتوفر نتيجة مسجلة.
